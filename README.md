# BWT Test Project

This is a web application built using the Laravel PHP Framework.

## Project Structure

This project follows the standard Laravel directory structure:

-   `app/`: Contains the core code, including models, controllers, and other business logic.
-   `bootstrap/`: Contains framework bootstrap files.
-   `config/`: Contains all the application's configuration files.
-   `database/`: Contains database migration, model factories, and seeders.
-   `public/`: The web server's document root, containing `index.php`.
-   `resources/`: Contains views, language files, and uncompiled assets.
-   `routes/` (or `app/Http/routes.php`): Defines all the application's route definitions.
-   `storage/`: Contains compiled Blade templates, file-based sessions, file caches, and other files generated by the framework.
-   `tests/`: Contains automated tests.

## Installation

To set up and run this project locally, follow these steps:

1.  **Clone the repository:**
    ```bash
    git clone <repository-url>
    cd bwt_test
    ```
    (Note: Assuming the user has already cloned it, this step is for completeness.)

2.  **Install PHP Dependencies:**
    Make sure you have Composer installed.
    ```bash
    composer install
    ```

3.  **Environment Configuration:**
    Create a copy of the `.env.example` file and name it `.env`:
    ```bash
    cp .env.example .env
    ```
    Generate an application key:
    ```bash
    php artisan key:generate
    ```
    Edit the `.env` file to configure your database connection and other environment variables.

4.  **Database Migration:**
    Set up your database and run the migrations:
    ```bash
    php artisan migrate
    ```

## Running the Application

After installation, you can serve the application using the Laravel development server:

```bash
php artisan serve
```

The application will typically be available at `http://127.0.0.1:8000`.
